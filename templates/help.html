📷 Media Sorter — Reference Manual

Complete guide to every feature, mode, and option.

What is Media Sorter?

Media Sorter is a local AI photo and video organiser that runs entirely on your PC. No cloud account, no subscription, no internet required after setup. It scans any folder — an SD card, a phone, a hard drive — and organises your files using artificial intelligence.

It started as a trail camera tool and grew into a general-purpose media organiser. Its two unique advantages over every paid competitor:

  • User-definable AI categories — type a sentence like "a photo of my red barn" and a new category is created instantly. No other tool offers this. Excire Foto ($199), ACDSee ($80/yr), and DigiKam cannot do this at all.
  • Visual similarity search — upload any reference photo and find all visually similar photos in any folder. Works with any subject: a specific animal, a face, a dish, a flower, a building. Zero configuration.

Everything is copy-based. Your original files are never touched, renamed, or deleted.

Starting & Stopping the App

The command prompt window

When you launch Media Sorter by double-clicking Launch Media Sorter.bat, two things open:

  1. A black command prompt window — this is the server engine. It must stay open the entire time you are using the app.
  2. Your web browser opens automatically at http://localhost:5000 — this is the actual interface you use.
Do not close the command prompt window while you are using the app. If you close it, the browser interface will immediately stop working — any scan in progress will be interrupted and results may be incomplete. The black window can be minimised to the taskbar; it does not need to stay visible.

How to stop the app when you are done

  1. Close your browser tab (or the whole browser window).
  2. Click on the black command prompt window in your taskbar to bring it up.
  3. Press Ctrl + C inside it — this cleanly shuts down the server. The window will then close on its own, or you can close it manually.
Nothing is lost when you close the app. All sorted files are already on disk. The next time you launch, the app starts fresh and ready to run.

Disk space

Media Sorter is copy-based — your originals are never touched. Every sorted file is a copy in your output folder. This means:

  • Your output drive needs roughly as much free space as the files you are sorting.
  • With multi-copy ON, files that match several categories are copied multiple times — budget extra space.
  • The app shows available space on your output drive below the Output field, and warns you before starting if it is very low.
  • If the drive fills up mid-sort the run will stop. Always check available space first for large libraries.

Quick Start

  1. Set your Source folder — where your photos are. Use the 📁 button to browse, or paste a path directly. For SD cards and phones, click 🔍 to auto-detect.
  2. Set your Output folder — where sorted results will be copied. Default is C:\MediaSorted. Can be anywhere except the exact same path as your source. Subfolders of source, parent folders, and different drives all work fine.
  3. Choose a mode from the button bar (Scan For Media is selected by default).
  4. For Sort By Category: toggle on the categories you want to find.
  5. Press the green Start button. Watch the live progress log.
  6. When done, click 📂 Open folder on any result card to view the files in Explorer.
Tip: For your first run, try Scan For Media on a small folder (100–200 photos) to get familiar with the tool before sorting your full library.

📷 Scan For Media

Recursively scans every subfolder of your source and copies all matching files into a single Collected/ folder in your output. No AI is used — this is purely a file-gathering operation.

When to use it

  • Your photos are scattered across many nested subfolders and you want them in one place before sorting.
  • Pulling everything off an SD card or phone before organising.
  • Creating a flat working copy of a folder tree.

Collision handling

If two files from different subfolders share the same filename, the second is automatically renamed IMG_001_1.jpg, IMG_001_2.jpg etc. No file is ever overwritten or lost.

Chain tip: After Scan For Media finishes, a clickable link appears below the source field: "click here to use Collected as source." Click it, then switch to Sort By Category for a two-pass workflow: gather first, then sort.

🔀 Sort By Category

The main AI sorting mode. Every file is analysed by the detection stack and copied into one or more labelled category folders. Files that match nothing go to Unsorted/ (if that option is on) or are skipped.

Options visible in this mode

  • Categories — toggle on only the ones you want. All are off by default.
  • Confidence slider — controls how strict the AI detectors are (see Confidence slider).
  • Copy to all matching categories — when ON, a file with both a person and an animal is placed in both Person/ and Animal/. When OFF, only the highest-priority match is used.
  • Copy non-matching files to Unsorted/ — when ON, every file that doesn't match any category is copied to Unsorted/. Turn this OFF for targeted searches — otherwise the entire library is copied.
  • Include date in folder path — files land in Animal/2024/June/ instead of flat Animal/.
  • Write XMP metadata tags — creates a sidecar .xmp file next to each sorted photo, readable by Lightroom and Capture One.

Face recognition in Sort mode

If you have Face Profiles registered, face recognition runs automatically on every file alongside the AI categories. Matched photos are copied to People_Mike/, People_Sarah/ etc. You don't need to do anything extra — just run Sort By Category.

Performance note: Leave "Copy non-matching to Unsorted/" OFF when you want only specific photos from a large library. With it ON, sorting 136 GB for cake photos would copy 136 GB — most of it to Unsorted/.

📅 Sort by Date

Reads the date from each file's EXIF metadata and copies it into Year/Month subfolders — for example 2024/June/IMG_0042.jpg.

  • Uses DateTimeOriginal EXIF tag (when the photo was taken).
  • Falls back to the file's last-modified date if no EXIF data is present.
  • Works on both photos and videos.
  • The confidence slider has no effect in this mode.
Tip: Run Sort by Date first to get a clean Year/Month structure, then use Sort By Category inside individual month folders for deeper organisation.

📍 Sort by Location

Reads GPS coordinates from each photo's EXIF data and sorts into CityName_CountryCode folders — for example Toronto_CA/ or Paris_FR/.

  • Photos without GPS data go into No_GPS/.
  • Uses offline reverse geocoding — no internet required.
  • Works best with photos taken on a smartphone (most phones embed GPS automatically).
  • Many dedicated cameras and trail cameras do not record GPS.

🔍 Find Photos With

The precision filter mode. Select two or more categories — only files that match ALL of them are copied. This is AND logic, not OR.

Example

Enable Animals and People → only clips where both a person AND an animal appear are found. A photo with only a person is skipped. A photo with only an animal is skipped.

Another example

Enable Sunset and Water → only photos that are both a sunset AND at a beach or lake are found.

Note: For best results keep the number of categories to two or three. The more categories you require, the fewer files will match all of them.

🖼️ Find Similar Photos

Upload any reference photo and Media Sorter finds all photos and videos in your source folder that look visually similar to it. No text labels, no categories — pure visual matching.

How to use it

  1. Switch to Find Similar Photos mode.
  2. Click Browse and choose your reference photo. The AI encodes it immediately (CLIP model loads ~350 MB on first run — this takes a minute; subsequent runs are instant).
  3. Wait for the green ✓ Reference encoded confirmation.
  4. Set your source folder and press ▶ Find Similar Photos.
  5. Results land in Similar_to_[filename]/ in your output folder.

What the AI actually looks at

The AI creates a numerical fingerprint of the entire image — composition, colours, framing, lighting, shapes. It does not look for a single specific object. If your reference photo is a man wearing a hat, the AI will weight the full scene: the human figure, the background, the overall colour palette. This means:

  • Results at low confidence (25%) are broad — other people photos, similar lighting conditions.
  • Results at high confidence (60–70%) are narrow — only photos with very similar overall appearance.
Best practice: Start at 50% confidence. If you get too few results, lower it. If you get unrelated photos, raise it. The slider auto-sets to 50% when you enter this mode.

Clearing the reference photo

Click the red ✕ Clear button that appears next to Browse after encoding. This removes the stored reference so you can upload a different one.

What it is NOT

This is not the same as Face Profiles. Find Similar Photos matches visual composition — lighting, scene, colours, shapes. For finding all photos of a specific person, use Face Profiles with Sort By Category instead.

🔁 Find Duplicates

Scans your entire source folder and separates files into two folders: Unique/ (one copy of each photo) and Duplicates/ (the extras).

How it works

Uses perceptual hashing — a technique that creates a visual fingerprint of each image. Two photos with the same fingerprint (within a small tolerance) are considered duplicates, even if they were:

  • Renamed to different filenames
  • Slightly re-saved at different quality levels
  • Copied from different backup folders

No AI model is needed. This mode is very fast.

After the scan

A 👥 Review Duplicates button appears in the results. Click it to open a grid of all files in Duplicates/. For each one you can Keep it (leaves it in place) or Trash it (moves to a Trash/ folder). Files in Trash are never permanently deleted — you have the final say.

How video duplicate detection works

For videos, the duplicate detector uses an exact-copy fingerprint: it checks the file size and reads the first and last megabyte of each file to generate a content signature. Two videos with the same signature are byte-for-byte identical — a true duplicate. This is much more reliable than visual frame comparison for trail camera footage, where the camera is fixed and the background never changes.

Video scenarioDetected as duplicate?
Exact copy of the same file (renamed or in a different folder)✓ Yes
Same video copied to two backup locations✓ Yes
Windows download duplicate — e.g. video(1).mp4 alongside video.mp4✓ Yes
Two different clips that look visually similar (same trail cam location)✓ Not flagged — correctly treated as unique
Re-exported or re-encoded at a different quality✗ Not detected — bytes differ
Edited or trimmed version of the same clip✗ Not detected — it is genuinely a different file

The goal is to find files you accidentally saved twice — not to find creatively similar content. An original clip and an edited version are genuinely different files; the app leaves that decision to you.

Separating photos from videos — two-pass approach

The File Types pills (Videos / Photos checkboxes) at the top of the Source & Output card let you control which file types are processed. Use this for a clean two-pass duplicate removal:

  1. Uncheck Videos, leave Photos checked. Run Find Duplicates. Photo duplicates go to Duplicates/, unique photos to Unique/. Review and trash photo duplicates.
  2. Uncheck Photos, check Videos. Run Find Duplicates again. Same result for videos. Review and trash true video copies.

Running the two types separately keeps your review screens manageable and lets you apply different judgement to photos vs. videos.

vs. the Duplicates category in Sort By Category: The "Duplicates" category toggle in Sort mode catches duplicates within the current sort run as a side effect. Find Duplicates mode is a dedicated full-library scan that compares every file against every other file — much more thorough for large libraries.

🗓️ Sort by Event

Groups your photos into events based on time gaps between consecutive photos. Any gap of more than 8 hours between photos starts a new event.

Output example

  • Event_2024-06-15/ — all photos from a single day
  • Event_2024-07-04_to_2024-07-06/ — a multi-day camping trip
  • Event_2024-12-25/ — Christmas photos

When to use it

Ideal when a single folder contains photos from many different occasions mixed together — a weekend hike, a birthday party, a work conference — and you want them automatically separated without manually creating folders. Similar to how Apple Photos groups photos into "memories."

Tip: Run Sort by Date first if you want Year/Month structure, then run Sort by Event on individual months to get event-level organisation within each month.

Confidence Slider

The slider controls how strict the AI has to be before it places a file in a category. It runs from 5% (very loose) to 60% (very strict). Default is 25%.

What it affects

  • MegaDetector categories (Animals, People, Vehicles) — the minimum detection confidence score required.
  • CLIP categories (Nature, Food, Sunset, etc. and all custom categories) — the minimum text-image similarity score required.
  • Find Similar Photos mode — how closely photos must match the reference image. The slider auto-sets to 50% in this mode.

What it does NOT affect

Categories marked ⚙ fixed rule use mathematical tests with no confidence score: Night/IR, Damaged, Screenshots, Selfies, Panoramas, and Duplicates. Changing the slider has zero effect on these.

Choosing the right level

  • 5–15% — very broad. Catches almost everything but produces many false hits.
  • 25% (default) — balanced for general sorting.
  • 40–50% — stricter. Good for Find Similar Photos or when false positives are a problem.
  • 60% — strictest. Misses some real matches but almost no false hits.
Trail camera note: MegaDetector was trained on trail camera footage and performs very well at 25% for animals. Going higher (50%+) may miss partially visible animals or distant wildlife.

Face Profiles

Face Profiles lets you register specific people and then have Sort By Category automatically find and organise their photos.

Step 1 — Register a person (one time only)

  1. Scroll to the Face Profiles card at the bottom of the page.
  2. Type the person's name in the Person's name field.
  3. Click Browse and select 1–5 reference photos. Use clear, well-lit, front-facing photos for best accuracy. Different angles, lighting, and ages improve recognition.
  4. Click Add 👤. The face detection model downloads (~110 MB on first use), reads the faces, and stores a mathematical fingerprint. This takes a few seconds. You only do this once per person.
  5. A chip appears: 👤 Mike (2) — the number is how many face embeddings were stored.

Step 2 — Find their photos

  1. Switch to Sort By Category mode (use the button on the Face Profiles card or the mode bar at the top).
  2. Enable any categories you also want sorted (or none — face recognition runs regardless).
  3. Press ▶ Sort By Category.
  4. Photos of registered people are automatically copied to People_Mike/, People_Sarah/ etc. alongside your other category results.
Accuracy: The face recognition model (InceptionResnetV1 / VGGFace2) is accurate for well-lit, clear frontal photos. Accuracy decreases with partial faces, poor lighting, or extreme angles. Using 3–5 varied reference photos significantly improves results.

Removing a profile

Click the ✕ on a person's chip in the Face Profiles card to permanently remove their profile.

Custom Categories

You can create your own AI categories at any time with no technical knowledge and no retraining of any model.

How to add one

  1. In the Categories section, find the ＋ Add your own category area at the bottom.
  2. Type a Category name — this becomes the folder name (e.g. "Red Barn").
  3. Optionally type a description — the more specific, the better. Example: "a photo of a red wooden barn in a farm field". If you leave this blank, a description is auto-generated from the name.
  4. Click Add ＋. The new category appears as a toggle immediately.

Custom categories are saved to custom_categories.json and persist across app restarts. They work exactly like built-in categories and respond to the confidence slider.

Writing good descriptions: Be specific and visual. "a photo of a red barn" works better than "barn." "a golden retriever puppy playing in grass" works better than "my dog." The AI matches based on visual content described in plain English.

Per-category threshold overrides

See Per-category thresholds below to fine-tune individual categories without affecting the global slider.

Per-Category Sensitivity Overrides

In Sort By Category and Find Photos With modes, a collapsible ⚙️ Per-category sensitivity overrides panel appears below the categories. This lets you set a different confidence threshold for each CLIP category, independent of the global slider.

  • Each CLIP category gets its own slider from 5% to 80%.
  • An override takes priority over the global slider for that category.
  • A ↺ button resets a category back to following the global slider.
  • Overrides are saved to category_thresholds.json and persist across restarts.
Example use: Food often produces false positives (a red flower might score as food). Set Food's override to 45% while keeping the global slider at 25% for everything else.

Multi-Copy

In Sort By Category mode, the Copy to all matching categories checkbox (default ON) controls what happens when a file matches more than one category.

  • ON — a trail camera clip with a deer and a person is copied to both Animal/ and Person/. You find it either way.
  • OFF — only the highest-priority match is used. Priority order: Night > Damaged > Screenshot/Selfie/Panorama > Duplicate > Animals/People/Vehicles > CLIP categories > Custom categories.
Your original file is never affected. All output is copy-only.

XMP Metadata Export

When Write XMP metadata tags is checked in Sort By Category mode, a sidecar .xmp file is created alongside each sorted photo.

  • XMP files are plain XML — readable by Adobe Lightroom, Capture One, and any XMP-compatible application.
  • The file contains: the category label(s) as keywords, a star rating scaled from the AI confidence score, and a creator tag (Media Sorter).
  • Example: IMG_0042.jpg → IMG_0042.xmp in the same folder.
  • XMP files are only written for photos (not videos).

Review Screens

After a Sort By Category run, two optional review screens may appear.

🔎 Review Uncertain Placements

Appears if any file was sorted with less than 40% AI confidence. Shows a grid with a thumbnail, the category it was placed in, and the confidence percentage. For each file you can:

  • ✓ Keep — accept the AI's placement and move on.
  • Move to… — reassign it to a different category folder using the dropdown.

👥 Review Duplicates

Appears if any files were detected as duplicates (also appears after Find Duplicates mode). Shows a grid of the duplicate files. For each one:

  • ✓ Keep — leave it in the Duplicates folder.
  • 🗑 Trash — move it to a Trash/ folder. Files in Trash are never automatically deleted. You can review and empty Trash manually in Explorer when you're certain.

Folder Browser

Click the 📁 button next to either the Source or Output field to open a click-to-navigate folder tree. Drive letters appear at the root. Click any folder to select it, expand it to see subfolders. Press Select ✓ to confirm.

You can also type or paste a path directly into either field.

Phone & Tablet Access

When Media Sorter starts, the terminal window shows two addresses:

  • http://localhost:5000 — this computer only
  • http://192.168.x.x:5000 — accessible from any device on the same WiFi

Open the second address on your phone or tablet browser. The full interface loads — you can start scans, browse results, and review duplicates from your phone while the processing runs on your PC. No app install required.

Chaining Scans

Media Sorter is designed for multi-step workflows. After any scan finishes, a link appears below the source field: "click here to use [output path] as source." Click it to chain directly into the next operation.

Recommended full-library workflow

  1. Scan For Media — gather everything from a messy folder tree into Collected/.
  2. Chain: set source to Collected/. Run Find Duplicates — separate unique files from extras. Review and trash duplicates.
  3. Chain: set source to Unique/. Run Sort by Date — get a clean Year/Month base structure.
  4. Run Sort By Category on individual month folders for specific searches as needed.

Targeted Searches (Finding Specific Photos in a Large Library)

To find specific photos — say, all cake photos from a 136 GB library — without copying everything:

  1. Switch to Sort By Category.
  2. Enable only the categories you want (e.g. Food, or a custom "Birthday Cake" category).
  3. Make sure Copy non-matching files to Unsorted/ is unchecked (it is by default).
  4. Press Start. Only your matched files are copied. The rest of the 136 GB is scanned but never touched.
If you check "Copy non-matching to Unsorted/" during a targeted search on a large library, every non-matching file is copied to Unsorted/ — this can mean copying hundreds of GB of files you don't need. Leave it unchecked for targeted searches.

General Tips

  • Source and output cannot be the exact same folder. If both fields point to the identical path the scan returns 0 files. Any other arrangement works: output inside source, source inside output, same drive, different drive — all fine.
  • Flexible path arrangements — all supported: source D:\Photos\ → output D:\Photos\Sorted\ ✓  |  source D:\Sorted\Unique\ → output D:\Sorted\ ✓  |  source D:\ → output C:\MediaSorted\ ✓. Only exact-same-path is blocked.
  • HEIC photos (iPhone format) are fully supported. They go through every detector exactly like JPEGs.
  • Videos are sampled at 2, 4, 6, 8, and 10 seconds. The AI analyses these frames — it does not process the full video.
  • AI models download once and are cached on your PC. MegaDetector (~290 MB) downloads on the first Sort By Category run. CLIP (~350 MB) downloads on the first CLIP-based category run or Find Similar Photos run. Face recognition (~110 MB) downloads on the first face profile addition.
  • The app runs locally. No files ever leave your computer. No internet is needed after the one-time model downloads.
  • Separating photos from videos: Use the 🎬 Videos and 🖼️ Photos pills at the top of the Source card. Uncheck one type per run to process them separately. This works in all modes including Find Duplicates.
  • Video duplicate detection uses an exact-copy fingerprint (file size + content signature). True copies are caught reliably regardless of filename. Visually similar clips that are different recordings are never falsely flagged. Re-encoded or edited versions are treated as separate files — correct behaviour, since they genuinely are different.
  • Multiple monitors / remote access: Open http://[your-pc-ip]:5000 on any device on your home network.

Frequently Asked Questions

My source shows 0 files found / "Complete — nothing copied."

This happens when source and output are set to the exact same folder path. The app protects against accidentally re-sorting its own output. Set your output to any different folder — it can be a subfolder of source, a parent folder of source, or on a different drive entirely. Only the exact-same-path case is blocked.

The confidence slider made no difference to my Night sort.

Night/IR uses a fixed mathematical rule — the slider has no effect on it. This is by design. See Categories Explained.

Find Similar Photos returned unrelated photos.

Try raising confidence to 50–60%. At 25%, the match is broad — any photo with similar overall composition and colour palette may match. See Find Similar Photos for a full explanation.

How do I search for photos of a specific person?

Use Face Profiles, not Find Similar Photos. Register the person once, then run Sort By Category — their photos land in People_[Name]/ automatically.

Where are my original files?

Exactly where you left them. Media Sorter copies files — it never moves, renames, or deletes originals.

The app sorted 200 photos as "Night" but many of them are not IR trail cam photos.

The Night/IR detector identifies near-grayscale images — which includes true IR trail cam photos, black-and-white photography, overcast outdoor scenes, and very faded photos. This is the intended behaviour. If you want only true trail cam IR photos, try adding a custom category with a description like "a black and white infrared trail camera photo of an animal at night" and use that instead.

Can I use this on a Mac or Linux?

The Python backend is cross-platform. The "Open folder" button and a few Windows-specific paths would need minor adjustments. For now it is optimised for Windows 11.

What about privacy? Does anything get sent to the cloud?

Nothing. All AI processing runs locally on your CPU. The app has no telemetry, no accounts, and no cloud connection of any kind. The only network activity is the one-time model download from public GitHub repositories.
